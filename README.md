# Contador-GET

Aplicación web desarrollada con Spring Boot que implementa un contador utilizando peticiones HTTP GET.  
El proyecto permite comprender el manejo de rutas, controladores y parámetros en aplicaciones Java con Spring MVC.

## Tecnologías utilizadas

- Java
- Spring Boot
- Spring MVC
- Maven
- HTML

## Funcionalidades

- Incremento de contador mediante solicitudes GET
- Manejo de rutas y controladores
- Renderizado de vistas web
- Ejemplo básico de arquitectura MVC

## Objetivo del proyecto

Practicar el uso de peticiones GET en Spring Boot y comprender el flujo básico entre cliente, controlador y vista en aplicaciones web Java.
